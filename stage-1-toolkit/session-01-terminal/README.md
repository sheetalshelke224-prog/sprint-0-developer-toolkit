# Session 1: The Hacker’s Terminal & Shell Mastery

## Core Commands Taught
* `pwd` — Print working directory (current path)
* `ls` / `ls -la` — List files and view hidden system files
* `cd <dir>` / `cd ..` — Navigate forward and backward in the directory tree
* `mkdir <dir>` — Create a new directory
* `touch <file>` — Create a new file
* `mv <old> <new>` — Rename or move files
* `cp <file> <copy>` — Copy files (`cp -r` for directories)
* `cat <file>` — Display file contents in the terminal

## Classroom Challenge
1. Verify location with `pwd`.
2. Move to Desktop (`cd Desktop`).
3. Create `eng-workspace` and navigate inside.
4. Create `labs` and `notes` directories.
5. Create `session1.txt` inside `labs`.
6. Run `ls -R` to inspect the full tree.
