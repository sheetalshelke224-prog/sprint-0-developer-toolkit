# Sprint 0: The Freshers' Developer Toolkit

A structured 12-session technical orientation series designed to transition first-year Computer Engineering students from everyday computer consumers into production-ready software developers.

## Program Architecture
* **Lead Architect & Instructor:** Shital Sharad Shelke (SY Computer Engineering)
* **Target Audience:** First-Year (FY) Computer Engineering Cohort (7 Divisions)
* **Format:** 12 interactive classroom sessions (Smartboard & interactive trace method)

## Curriculum Roadmap

### Stage 1: The Engineer’s Toolkit
* **Session 1:** The Hacker’s Terminal & Shell Mastery (CLI navigation, file systems)
* **Session 2:** VS Code Configuration & CLI Compilation (Headless execution)
* **Session 3:** Version Control Fundamentals with Git (Local commits, staging)
* **Session 4:** Remote Repositories & GitHub Profiles (Open source onboarding)

### Stage 2: Clean Code & Systematic Debugging
* **Session 5:** Functional Decomposition & The DRY Principle
* **Session 6:** Systematic Debugging, Stack Traces & Runtime Errors
* **Session 7:** Algorithmic Logic & Edge-Case Boundary Traps

### Stage 3: Object-Oriented Design & Intuitive Complexity
* **Session 8:** Object-Oriented Modeling (Encapsulation, State & Behavior)
* **Session 9:** Modular Architecture & Multi-File C++ Projects
* **Session 10:** Intuitive Big-O Complexity Analysis

### Stage 4: Professional Workflows & Industry Practices
* **Session 11:** Git Branching, Pull Requests & Code Reviews
* **Session 12:** AI as a Pair Programmer & Retrospective
